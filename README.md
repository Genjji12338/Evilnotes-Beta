## ✳ Evilnotes v1.0

Dein digitales Notizbuch für Android. Deine Gedanken. Dein Raum.

### Features
- 📓 Mehrere Notizbücher anlegen und verwalten
- ✍️ Direkt auf der Seite schreiben
- 🎨 Dunkles, modernes Design
- 🔒 Alles bleibt lokal auf deinem Gerät, kein Konto, kein Server
- 🚫 Keine Berechtigungen nötig

### Installation
1. `Evilnotes-debug.apk` unten unter **Assets** herunterladen
2. Datei auf dem Handy öffnen
3. Falls gefragt: „Installation aus unbekannten Quellen" für den Browser oder Dateimanager erlauben
4. Installieren und Evilnotes starten

### Systemanforderungen
- Android 6.0 (API 23) oder neuer
