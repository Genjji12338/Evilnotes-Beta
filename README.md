## ✳ Evilnotes v1.0

**Your thoughts. Your space.**

Evilnotes is a digital notebook for Android. Create notebooks, write directly on the page, and keep everything private on your own device.

### ✨ Features
- 📓 Create and manage multiple notebooks
- ✍️ Write directly on the page
- 🎨 Clean, modern dark design
- 🔒 Local storage only: no account, no server, no cloud
- 🚫 No permissions required
- 🪶 Tiny download (about 48 KB)

### 📲 Installation
1. Download `Evilnotes-debug.apk` from the **Assets** section below
2. Open the file on your phone
3. If prompted, allow installation from unknown sources for your browser or file manager
4. Tap **Install**, then launch Evilnotes

### 📋 Requirements
- Android 6.0 (API 23) or newer
- No special permissions

### 🔐 Privacy
All notes are stored locally on your device. Evilnotes does not request any permissions and does not send data anywhere. Note that uninstalling the app will delete your notes.

### ⚠️ Please note
This is a **debug build** intended for testing. It is signed with a debug certificate, so Android may show a warning during installation. You may run into bugs or unfinished features.
